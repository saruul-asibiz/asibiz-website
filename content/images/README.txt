Upload cover pictures for interviews and posts into this folder (Add file > Upload files).

- JPG, PNG or WEBP.
- Interview covers look best tall (9:16, like the reel itself). Post pictures are shown square.
- Use simple file names without spaces, e.g. nepal-4.jpg, office-party.jpg
- Then write the exact file name after "image:" in content/interviews.txt or content/posts.txt.

Large pictures are fine: the website makes smaller copies automatically.
